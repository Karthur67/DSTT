# Project 3 – Matrix multiplication, inversion, and photo filters

Linear Algebra (MT1007) – Python version of the MATLAB project.

## Install
```
pip install -r requirements.txt
```

## Run
Put `daylilies.jpg` in the same folder as `lab03.py`, then:
```
python lab03.py
```
All 14 tasks run in order; the figures appear at the end.
Answers to Q1–Q6 are written as comments under the related tasks.

## Files
- `lab03.py` – full code (Tasks 1–14, answers Q1–Q6)
- `daylilies.jpg` – input image from the project
- `requirements.txt` – required libraries
